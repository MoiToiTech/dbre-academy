# Security

This repository is training material. The lab is designed to run on a single
machine: every port binds to `127.0.0.1`, and the credentials in
`labs/` are public, lab-only values. Do not expose the lab to a network and
do not reuse its passwords.

If you find a security problem — for example a script that could expose a
student's machine, or a lesson that teaches an unsafe practice without
saying so — e-mail <connect@moitoi.tech> with the details. Please do not
open a public issue for it. We aim to reply within five working days.
