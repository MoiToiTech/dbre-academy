# Code of conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, criticise ideas rather than
people, and help newcomers. Harassment and personal attacks are not
tolerated.

Report unacceptable behaviour to <connect@moitoi.tech>. Reports are
handled confidentially by the maintainers at MoiToi.TECH.
